# 고령자 돌봄 업무 기능 명세서

창원 지역 고령자 돌봄 담당자의 대상자 확인 우선순위, 방문과 전화 계획, 현장 기록, 복지혜택 지원, 기관 연계와 보고 기능을 정의한다.

원본  [임시 기능 명세서 (수정 중)](https://www.notion.so/3fa679a9d62b809a9c8cd0e94b2b4e04)  |  원본 표시 편집일 10월 16일  |  확인일 2026년 10월 29일

원문의 항목, 식별자, 조건, 제안과 미확정 사항을 유지한 문서화본이다. 출처 링크는 클릭할 수 있으며, 원문에 기재된 자료 확보 상태와 일정은 원문 기준으로 보존했다.
