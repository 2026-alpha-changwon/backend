# 고령자 돌봄 데이터 목록

고령자 돌봄 업무에 필요한 공개 데이터와 가상 사례관리 데이터의 출처, 필드, 확보 방법, 갱신 주기 및 정제 책임을 정리한다.

원본  [데이터 목록 (수정 중)](https://www.notion.so/3fa679a9d62b80e8bed4fc0426529118)  |  원본 표시 편집일 10월 16일  |  확인일 2026년 10월 29일

원문의 항목, 식별자, 조건, 제안과 미확정 사항을 유지한 문서화본이다. 출처 링크는 클릭할 수 있으며, 원문에 기재된 자료 확보 상태와 일정은 원문 기준으로 보존했다.

출처 12개  ·  데이터 23개  ·  정제 작업 9개  ·  확보 과제 6개

## 필요한 데이터 목록

P0는 업무 흐름 필수, P1은 지역 화면과 지도, P2는 고도화다. 주기는 원천 기관의 갱신과 별도로 플랫폼이 수집·재조회할 권장 주기다.

- **데이터 ID**: D01
- **필요한 필드**: regionCode, name, level, parentCode, codeSystem, referenceDate
- **단위와 연결 키**: 구·행정동
- **우선순위·사용 화면**: P0 공통 선택·필터
- **출처·MVP 확보 방식**: S01/S03 및 공식 코드 대응표; 공통 코드 테이블 구축
- **권장 갱신**: 구역 개편 시

### D02

- **데이터 ID**: D02
- **필요한 필드**: referenceMonth, populationTotal, age65Plus, age70Plus, age75Plus, age80Plus
- **단위와 연결 키**: 행정동·명
- **우선순위·사용 화면**: P1 S09·S10
- **출처·MVP 확보 방식**: S01 우선, S02 대체; 연령별 합산은 백엔드 가공

- **출처·MVP 확보 방식**: S03 가능한 분류 확인; 불가능한 필드는 null

## 수집과 정제 책임

원본 파일·sourceUrl·기준일·다운로드일·이용조건을 보관하고 원본→정제→화면 필드 대응표를 작성한다. 프론트는 정제 DTO와 화면용 출처 정보를 받는다. 공개 CSV를 프론트에서 매번 직접 파싱하거나 외부 API 키를 포함하지 않는다.

### 행정동 통일

- **작업**: 행정동 통일
- **구체적인 처리**: MOIS·SGIS·시설의 코드 체계를 대응표로 연결; 법정동과 행정동 이름만으로 결합하지 않음; 변경 이력·적용일 보관
- **오류 시 표시**: 미매핑 지역은 별도 목록

### 인구 집계

- **작업**: 인구 집계
- **구체적인 처리**: 같은 월 자료에서 전체·65/70/75/80세 이상 합산; 합계 행 중복 제외
- **오류 시 표시**: 기준월 불일치 시 지표 계산 중단

### 시설 위치

- **작업**: 시설 위치
- **구체적인 처리**: 주소 정규화 후 좌표 변환; 원본 resourceId와 공유 locationId 분리; 같은 주소의 서로 다른 경로당은 유지
- **오류 시 표시**: 변환 실패 시설은 목록만 제공

### 공간 좌표

- **구체적인 처리**: 원본 좌표계 기록, 프론트 API는 WGS84 lat/lng; GeoJSON은  \[lng,lat\]
- **오류 시 표시**: 지도 렌더 실패 시 표

### 거리
